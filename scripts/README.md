# Migration scripts

`bun run build` runs Vite directly. It does not execute any of the historical
source-patching scripts below. The workflow is read-only and fails if install or
build changes tracked files or creates unignored files.

The scripts are retained as historical evidence; do not run them as a build step.

| Script | Review outcome |
| --- | --- |
| `sync-main-final-fixes.mjs` | Calendar fixes and the Fahrtenbuch Excel sheet are now in source. Standalone PDF generation and the staging PWA guard were already in source. |
| `finalize-navigation-ui.mjs` | Navigation changes are now in source. A link from the Fahrtenbuch export page to trip/vehicle management preserves editing access. |
| `cleanup-kalkulation-ui.mjs` | Never wired into the current build. Retained and **not executed**: its removal of tender-document state/UI would discard a main feature; its alternate Fahrtenbuch navigation also conflicts with the final navigation script. |
| `migrate-storage.mjs` | Retained, not executed. Uses explicit destination credentials and a fixed owner/file-count manifest. `upsert: false` prevents overwriting objects, but partial uploads and destination correctness still require a reviewed migration plan. |

Routes are generated by TanStack Start. The four migration routes are now included
in the committed `src/routeTree.gen.ts`. Generate and commit route changes during
development; CI must never commit them back automatically. Disabling the Start
route crawler was tested and rejected because the framework requires its crawl
result during builds.

See `CLEANUP_REPORT.md` and `docs/cleanup/DATABASE_REVIEW.md` before considering any
database or deployment action. No script or workflow added by this cleanup deploys
to Cloudflare or applies SQL.
